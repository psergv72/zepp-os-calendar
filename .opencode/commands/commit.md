Сохранить текущие изменения в git. Сначала показать `git status`, `git diff --stat` и `git log --oneline -5`. Затем проиндексировать всё через `git add -A` и создать коммит с сообщением: `$ARGUMENTS`. Рабочая директория — корень репозитория `C:\_Soft\_ZepOS\calendar`. Если $ARGUMENTS пуст, спросить у пользователя сообщение коммита. Не пушить.
