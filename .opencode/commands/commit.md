Рабочая директория — корень репозитория `C:\_Soft\_ZepOS\calendar`.

1. Выполни `git status` в корне репозитория. Если нет изменений — завершись.
2. Выполни `git add -A`.
3. Если `$ARGUMENTS` не пуст, используй его как сообщение коммита. Иначе сгенерируй сообщение самостоятельно на основе `git diff --cached --stat` (короткое, как в Conventional Commits, на русском).
4. Выполни `git commit -m "<сообщение>"`.

Не задавай пользователю никаких вопросов. Не пуши.
