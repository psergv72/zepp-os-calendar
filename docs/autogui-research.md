# AutoGUI for ZeppOS — Исследование применимости в Calendar

## Что такое AutoGUI

**AutoGUI** (`@silver-zepp/autogui` v1.2.9) — библиотека для быстрого прототипирования GUI на ZeppOS с авто-позиционированием. Разработана Silver / Zepp Health.

Установка: `npm i @silver-zepp/autogui`

API предоставляет виджеты: `text`, `button`, `image`, `circle`, `arc`, `fillRect`, `strokeRect` + авто-раскладка по строкам (row-based layout), группировку, события `onRelease`/`onPress`.

## Текущая архитектура Calendar

| Компонент | Реализация |
|-----------|-----------|
| Заголовок месяц+год | `hmUI.widget.TEXT` с ручными px-координатами |
| Кнопки < и > | `hmUI.widget.BUTTON` с click_func |
| Дни недели (7 шт) | `hmUI.widget.TEXT` в цикле, ручной x/y расчёт |
| Сетка 6×7 = 42 ячейки | `hmUI.widget.TEXT` в цикле, ручной px() расчёт |
| Кружок «сегодня» | `hmUI.widget.CIRCLE` с динамическим CENTER_X/Y |
| Кнопка «Сегодня» | `hmUI.widget.BUTTON` с click_func |
| Раскладка | Отдельный `index.r.layout.js` со всеми px() константами |

**Сложность**: 179 строк `page/index.js` + 92 строки `page/index.r.layout.js`. Вся геометрия считается вручную.

## Оценка применимости AutoGUI для Calendar

### 1. Полная замена на AutoGUI

| Секция | Как сделать через AutoGUI | Сложность |
|--------|--------------------------|-----------|
| `< Янв 2026 >` | 3 виджета в одной строке: `gui.button("<")`, `gui.text("Янв 2026")`, `gui.button(">")` | Низкая |
| `Пн Вт Ср Чт Пт Сб Вс` | 7 `gui.text()` в одной строке | Низкая |
| Сетка 6×7 | 6 строк по 7 `gui.button()` / `gui.text()` на строку | Средняя |
| Обводка «сегодня» | `gui.circle()` внутри группы с текстом ячейки или отдельно | Средняя |
| Кнопка «Сегодня» | `gui.button()` | Низкая |

**Проблемы полной замены:**

1. **Все строки равной высоты** — AutoGUI делит `DEVICE_HEIGHT` на количество строк поровну. В calendar 9 строк (1 навигация + 1 дни недели + 6 сетка + 1 сегодня). Высота строки = 480/9 ≈ 53px. Для навигации это нормально, но для сетки может быть маловато (сейчас CELL_H = px(38) + отступы).

2. **Проценты колонок** — `rowLayout()` нужно вызывать с 7 одинаковыми значениями: `rowLayout(14.28, 14.28, ..., 14.28)`. Из-за округления возможно смещение последней колонки на 1-2px.

3. **42 виджета + цикл перерисовки** — `.update()` на одной ячейке запускает `gui.render()`, который проходит по всем виджетам. Это 42+ итераций при каждом клике.

4. **Виджет «сегодня»** — кружок под текстом ячейки. AutoGUI не поддерживает z-order / слои. Придётся либо городить группы, либо отказаться от кружка в пользу текстового выделения (полужирный / другой цвет).

5. **Разный цвет/стиль ячеек** — каждая ячейка может быть:
   - числом текущего месяца (белый)
   - числом другого месяца (тусклый)
   - выходным (красный `WEEKEND_COLOR`)
   - «сегодня» (белый на оранжевом фоне / кружке)
   
   Через AutoGUI это делается `.update({ color: ... })`, что требует хранения ссылок на все 42 виджета.

6. **Кнопки с click_func для ячеек** — если использовать `gui.button()` для каждой ячейки, то все ячейки получат фон кнопки (normal_color), что визуально не соответствует текущему чистому дизайну (только текст).

### 2. Гибридный подход (рекомендуемый)

AutoGUI используется для **статических / структурных частей**, а сетка остаётся на ручном `hmUI`.

```
[   <    Янв 2026    >   ]  ← AutoGUI: rowLayout(15, 70, 15)
[  Пн  Вт  Ср  Чт  Пт  Сб  Вс ]  ← AutoGUI: rowLayout(14.28...)
[  1   2   3   4   5   6   7  ]  ← hmUI (ручной)
[  8   9  10  11  12  13  14  ]  ← hmUI
[ 15  16  17  18  19  20  21  ]  ← hmUI
[ 22  23  24  25  26  27  28  ]  ← hmUI
[ 29  30  31                   ]  ← hmUI
[          Сегодня            ]  ← AutoGUI
```

**Преимущества гибрида:**
- Сетка остаётся быстрой и контролируемой (ручное обновление 42 виджетов через `setProperty`)
- Навигация, дни недели и кнопка «Сегодня» получают авто-раскладку
- Меньше кода в layout-файле — px-константы для сетки всё ещё нужны, но остальное AutoGUI рассчитывает
- Проще поддержка разных экранов (AutoGUI адаптируется под `DEVICE_WIDTH/HEIGHT`)

```bash
npm i @silver-zepp/autogui
```

### Шаг 2: Переписать `page/index.js`

```javascript
import AutoGUI from "@silver-zepp/autogui";
const gui = new AutoGUI();
```

### Шаг 3: Заменить заголовок и навигацию

```javascript
// Было:

hmUI.createWidget(hmUI.widget.BUTTON, { ...NAV_PREV, click_func: ... });
hmUI.createWidget(hmUI.widget.BUTTON, { ...NAV_NEXT, click_func: ... });

// Стало:

gui.rowLayout(12, 76, 12);
```

// Было: цикл с ручным x

## Сравнение подходов

| Критерий | Текущий (ручной) | AutoGUI (полный) | Гибрид |
|----------|-----------------|------------------|--------|
| Строк кода (page) | 179 | ~150-160 | ~150-160 |
| Строк кода (layout) | 92 | 0 (не нужен) | ~30 (только сетка) |
| Адаптация к экрану | Нужно менять px() | Авто | Авто для верха/низа |
| Производительность сетки | Оптимально | Средне (42 виджета) | Оптимально |
| Контроль дизайна | Полный | Ограничен строками | Полный |
| Сложность поддержки | Высокая (ручная геометрия) | Средняя | Низкая |

## Вывод

**AutoGUI** — полезная библиотека, но **полная замена нецелесообразна** для календаря из-за:
1. Фиксированной равной высоты строк — календарная сетка и навигация требуют разной высоты
2. Отсутствия z-order / слоёв — сложно сделать кружок «сегодня» под текстом
3. 42 виджета в AutoGUI медленнее прямого `hmUI.createWidget()` при массовых обновлениях

**Рекомендуется гибридный подход**:
- AutoGUI для навигации (`< Янв 2026 >`), дней недели и кнопки «Сегодня»
- Ручной `hmUI` для календарной сетки (6×7 + кружок сегодня)

Это сократит код, улучшит читаемость, упростит поддержку и адаптацию под разные экраны без потери производительности и контроля над дизайном.
