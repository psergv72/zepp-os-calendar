# Project notes

## Build & deploy

После каждого изменения кода нужно пересобрать и отправить приложение в эмулятор:

```bash
zeus dev -t "Amazfit Balance 2"
```

Команда собирает проект, отправляет в эмулятор и остаётся в режиме слежения за изменениями. При повторных изменениях достаточно сохранить файл — zeus пересоберёт и обновит автоматически.

## Названия месяцев

Названия месяцев должны быть длиной 3 символа — первый заглавный, остальные строчные.
Примеры: Jan, Feb, Mar / Янв, Фев, Мар.

## Названия дней недели

Названия дней недели должны быть длиной 2 символа — первый заглавный, второй строчный.
Примеры: Mo, Tu, We / Пн, Вт, Ср.
