# Календарь / Calendar

Приложение-календарь для Zepp OS. Поддерживаемые устройства:

- [Amazfit Balance 2](https://www.amazfit.com/products/balance2)
- [Amazfit Active 2 Round](https://www.amazfit.com/products/amazfit-active-2)

На других устройствах не тестировалось.

Отображает сетку месяца с навигацией по месяцам, поддержкой круглого экрана и локализацией (русский / английский).

## Установка на часы

Список версий для установки через QR-код:  
[https://psergv72.github.io/zepp-os-calendar/versions.html](https://psergv72.github.io/zepp-os-calendar/versions.html)

## Разработка

```bash
npm run dev    # сборка + отправка в эмулятор
npm run build  # публикация .zab-файла в dist/
```
