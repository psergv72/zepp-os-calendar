# Project notes

## Build & deploy

После каждого изменения кода нужно пересобрать и отправить приложение в эмулятор через `npm run dev`:

```bash
npm run dev
```

Команда подключается к запущенному эмулятору, собирает проект и отправляет обновление. `dev` работает в режиме слежения — для выхода нажми `Ctrl+C`.

Для публикации (сборка `.zab`-файла в `dist/`):
```bash
npm run build
```

Перед сборкой автоматически увеличивается номер билда (версия в формате `0.2.{build}`). Если нужно только обновить версию без сборки — выполнить `npm run prebuild`.

## Названия месяцев

Названия месяцев должны быть длиной 3 символа — первый заглавный, остальные строчные.
Примеры: Jan, Feb, Mar / Янв, Фев, Мар.

## Названия дней недели

Названия дней недели должны быть длиной 2 символа — первый заглавный, второй строчный.
Примеры: Mo, Tu, We / Пн, Вт, Ср.
