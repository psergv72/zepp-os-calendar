# Project notes

## Build & deploy

После каждого изменения кода нужно пересобрать и отправить приложение в эмулятор:

```bash
npm run build
```

Перед сборкой автоматически увеличивается номер билда (версия в формате `0.2.{build}`). Команда собирает проект в папку `dist/` — оттуда можно забрать `.zab`-файл для публикации.

Для разработки с запуском в эмуляторе (режим слежения):
```bash
npm run dev
```

Если сборка уже запущена и нужно только обновить версию — выполнить `npm run prebuild` в другом терминале.

## Названия месяцев

Названия месяцев должны быть длиной 3 символа — первый заглавный, остальные строчные.
Примеры: Jan, Feb, Mar / Янв, Фев, Мар.

## Названия дней недели

Названия дней недели должны быть длиной 2 символа — первый заглавный, второй строчный.
Примеры: Mo, Tu, We / Пн, Вт, Ср.
